## 📘 Description
This project was built with **Angular version 18**.  
It is a **study project** created to practice building a **reactive page for managing and creating tasks**, showcasing how **Angular** simplifies the development of **single-page applications (SPAs)**.

---

## 🚀 Development server
Run the following command to start a development server:

```bash
ng serve
```

Then navigate to [http://localhost:4200/](http://localhost:4200/).  
The application will automatically reload if you change any of the source files.

## 🧱 Code scaffolding

## 🏗️ Build
Run the following command to build the project:

```bash
ng build
```
